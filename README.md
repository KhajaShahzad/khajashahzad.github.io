# Khaja Shahzad Portfolio

Premium React/Vite portfolio rebuilt from the supplied reference portfolio and populated with the resume-backed profile and projects of Khaja Shahzad Mazhar Hussain.

## Run locally

```bash
npm install
npm run dev
```

## Optional contact form

Copy `.env.example` to `.env` and add your EmailJS credentials. Without them, the email address shown in the contact section remains available as the direct contact method.

## Build

```bash
npm run build
```
